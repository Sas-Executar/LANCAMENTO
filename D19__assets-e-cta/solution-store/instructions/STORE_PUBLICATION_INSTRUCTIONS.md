# Publicação — Oficina

Publicar somente após G1–G5 verdes. Validar CTA/download, claims, privacidade, licenças, acessibilidade, formatos e URLs finais.

build_ready, render_ready ou store_submission_ready não equivalem a publish_ready.

Após publicação, registrar URL e data no Release Manifest e promover lifecycle para PUBLISHED.
