GLOBAL DEFINITION OF DONE
A run is complete only when:
- requested deliverables exist;
- the relevant workflow acceptance criteria pass;
- no duplicate source of truth was created;
- routes and dependencies are documented;
- tests appropriate to the change pass;
- unresolved items are explicit;
- handoff output is produced;
- mutation logging instructions are supplied when a governed repository was modified.
