2. Inventory current content model and live fields.
3. Define the minimum canonical Article schema and only add fields supported by product requirements.
4. Define taxonomy entities and whether categories/tags are controlled vocabulary or free-form.
5. Define author/media/related-content relationships.
6. Define lifecycle states and allowed transitions.
7. Define slug generation, uniqueness, canonical URL, SEO title/description and social metadata behavior.
8. Define preview/draft visibility and authentication requirements if current stack supports them.
9. Implement schema changes compatibly; add migrations only when required and authorized.
10. Validate existing content against the new contract and report incompatibilities.
