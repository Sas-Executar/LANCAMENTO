# Triage

Área temporária para entradas cuja rota ainda não pode ser determinada com segurança.

Triage não é destino canônico. Cada nota deve conter `task_id`, origem, resumo, rotas candidatas, dúvida de roteamento e ação necessária. Após resolução, mover o conteúdo para uma única rota e registrar a decisão no receipt.
