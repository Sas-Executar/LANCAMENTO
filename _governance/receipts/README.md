# Change receipts

Cada alteração realizada por um agente deve produzir um receipt independente. O arquivo registra o que entrou, onde foi roteado, o que mudou, como foi validado e o que ficou pendente.

Padrão: `_governance/receipts/YYYY-MM/<task-id>.md`.

Use `_governance/templates/CHANGE_RECEIPT.md`. Receipts preservam a trilha histórica da execução.
